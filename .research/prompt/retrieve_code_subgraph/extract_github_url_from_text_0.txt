# Paper Outline
The core methodology is an iterative LLM-driven objective discovery pipeline. An LLM (GPT-4) is iteratively prompted to propose and implement new preference optimization loss functions in PyTorch code. These proposed functions are evaluated based on their performance metrics (e.g., MT-Bench scores) on a downstream validation task. This performance feedback is then provided back to the LLM as in-context examples for iterative refinement. The process aims to perform meta-optimization, searching for objective functions that maximize expected downstream performance. DiscoPOP itself is defined as a dynamically weighted sum of the logistic loss and exponential loss, where the weights are determined by a sigmoid calculation of the log-ratio difference with a temperature parameter.
